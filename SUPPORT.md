# Layerdeck: support policy

- **Where:** open an issue in this repository (https://github.com/ChympyJames/layerdeck/issues). Please include your Windows version, Stream Deck model, Stream Deck app version, Affinity version (Help ▸ About) and what you pressed or turned.
- **Logs that help:** the plugin log in `%APPDATA%\Elgato\StreamDeck\Plugins\com.chympyjames.layerdeck.sdPlugin\logs`. It contains no document contents, but check it before attaching.
- **Response time:** usually within 3 business days.
- **Supported:** Windows 10/11, Stream Deck app 7.1 or newer, Affinity 3.3 or newer. macOS isn't supported yet.
- **Refunds:** handled by the Elgato Marketplace under its refund policy.
